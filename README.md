# SeedHammer hardware

CAD models of the Seed controller and the Hammer and II engraving machines as STEP.

| File | Model | Source |
|---|---|---|
| `hammer/hammer.step` | Hammer engraving machine, complete assembly | Fusion `Hammer_V3P` |
| `seed/seed.step` | Seed controller, complete assembly | Fusion `seed_one_nobattery` |
| `II/II-v74.step` | II engraving machine, complete assembly | Fusion `SH2_P` |

The Hammer file is in centimetres, the others in millimetres.
